# Sovrn Commerce API spike (#17)

Date: 2026-11-07. Tested read-only with the existing account keys (site key belongs to the "Twitter.com" campaign, status APPROVED). No links, clicks, or sites were created. No secrets appear below.

## Verdict

**(b) Affiliate-link router only, with limited use as a supplementary price signal. Not suitable as the M2 first connector.**
The only keyword-searchable product API (Price Comparison v3.5) is a general-merchandise index: for grocery queries it returns mostly unrelated products (home goods, beauty, farm supplies), returns one best offer per merchant, and has no UPC, brand, size, availability, or timestamp fields. Package size exists only inside titles, and many titles carry none. Sovrn is, however, a good fit for monetizing links: the merchant network includes Walmart, Target, Amazon, Costco, Kroger, Instacart, Stop & Shop, Shaw's and Walgreens.

## 2. Query results (Price Comparison v3.5, `usd_en`, `limit=50`)

HTTP 200 on all. 10 to 16 offers per query, one per merchant, sorted by price. Fields returned per offer: `id`, `name`, `merchant{id,name,logo}`, `salePrice`, `retailPrice`, `discountRate`, `currency`, `image`, `thumbnail`, `deeplink`, `affiliatable`, `epc`.
**Absent:** UPC/GTIN, brand, size/quantity, availability, timestamps, category.

Relevance was poor for generic grocery terms: "2% milk" returned moisturizing milk lotions; "large eggs" returned egg figurines and fishing bait; "ground coffee" returned instant coffee, cold brew. Specific brand+product queries worked better ("Horizon organic whole milk gallon": instacart, Kroger, Walmart, Sam's Club; "Folgers classic roast ground coffee 30.5 oz": Kroger $7.99, Target $10.79). Grocery merchants appeared sparsely (Walmart, Target, instacart.com, Kroger, Sam's Club, Walgreens, Thrive Market, Amazon on one query). Costco, Shaw's, Stop & Shop, and BJ's never appeared in results.

Barcode lookup: a Diet Coke 12-pack UPC returned 4 offers; two other grocery UPCs returned zero. Coverage is thin.

## 3. Package size

Not structured anywhere in the affiliate API. Titles are inconsistent (some have count and size, some none, e.g. "Absorbent Paper Towels"). The non-affiliated URL endpoint also lacks size fields per its docs. shopwit's normalizer would have to parse titles and would drop many offers.

## 4. Merchant coverage / affiliation

Approved Merchants API (`/merchants/rates/summaries`, 45,502 merchant groups) answers "is merchant in network": found Walmart (384), Target (390), Amazon (185), Costco (148939), Kroger (140570), instacart.com (104763), Stop & Shop (154258), Shaw's (201352), Walgreens (414), bjs.com (2254, name match only; confirm it is BJ's). Sam's Club only appears as Mexico. `rates` came back empty (no CPA/CPC rates) for these groups under this campaign, so commission rates are unknown from the API. Each offer also carries `affiliatable` and `epc` (all true in samples).

Caveat: Link Check returned `affiliatable: false` for plain Walmart/Target/Amazon/etc. URLs and for real product URLs under this key (the key's campaign is "Twitter.com", so this likely reflects this campaign, not shopwit's). Needs retest with a shopwit site key.

## 5. Link wrapping and terms

- Redirect format: `https://sovrn.co?key=<SITE_KEY>&u=<url-encoded destination>`; optional `cuid` (click ID, up to 2048 alphanumeric chars), `utm_*`, `bf` (bid floor), `fbu` (fallback URL). Offer `deeplink`s use `redirect.viglink.com` with `u`, `key`, `prodOvrd`, `opt`, `x`, `prdId`.
- A shopwit `/go/` redirect can 302 to a sovrn.co URL built server-side with a `cuid`.
- Public Sovrn docs say nothing about caching/display/freshness of API prices. The docs defer to the publisher contract and support@sovrn.com. The Sovrn disclosure article requires a disclosure on every page with affiliate links, above the fold, not only in legal pages. Sites go through an approval review.

### Design implications
1. Daily-refreshed cache fails Amazon's 24 h cap by a margin of zero and Walmart's 24 h update rule; refresh at least every 12 h or show a "price as of <timestamp>" per offer with the Amazon disclaimer.
2. Do not store merchant images for Amazon; hotlink or skip. Store ASIN only.
3. Walmart's bans on obscuring links, intermediate pages, and price tracking conflict with a `/go/` redirect and any price history. Using Sovrn's `sovrn.co` wrapper may sit under Sovrn's umbrella terms, but this must be confirmed in writing.
4. Rank by unit price independent of commission: no public term seen that forbids it, but Amazon requires lowest-price display in comparison format; supports the current design.
5. Add the Amazon disclosure sentence plus a generic affiliate disclosure above the fold on every page with links.
6. Obtain the Impact and CJ contract text (Target, Instacart, Costco) only after approval; plan for the possibility they restrict cached prices.
