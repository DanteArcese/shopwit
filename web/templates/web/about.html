About UnitPricer

Who runs it

UnitPricer is run by one person, Dante Arcese, as a free side project.

What it does

It compares grocery and household products by price per unit (per ounce, per count, per litre), so a bigger pack is not mistaken for a better deal. Prices show when they were last seen.

New to unit prices? Read how to read unit price tags.

Why

Fair unit prices, ranked only by price per unit and never by commission. No AI ranks results or writes product or price text.

How it is funded

Through affiliate links, where configured. See the disclosure.

Where the data comes from

See "Stores we cover" on the home page, and the data sources listed in the disclosure.

Open source

The code is open source under the AGPL-3.0: github.com/DanteArcese/unitpricer.

Contact
